# The Beautiful Data

An interactive field guide to football: what gets recorded, the models people build on it (xG, xT, VAEP, pitch control, ghost teams, passing networks, forecasting, game theory) and where the field is heading.

- Source code: https://github.com/JGalego/football
- Lite edition (static snapshots, no third-party row-level data): https://jgalego.github.io/football

Event and 360 data provided by **StatsBomb** (https://github.com/statsbomb/open-data). Tracking sample data by Metrica Sports. International results (CC0) by martj42; Transfermarkt valuations (CC0) by dcaribou. Photo, audio and video from Wikimedia Commons, credited inside the notebook.
